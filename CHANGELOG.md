# Changelog

Release drafts automatically include the matching entry here when present, plus a commit log since the previous version. For user-facing notes, add a concise version entry before bumping the app version.

## 0.12.0

- Export and import saved signatures and text to move them to another phone. Existing entries are preserved and identical copies are skipped.
- Support Android phone-to-phone data transfers, including drafts, on compatible devices.
- App text is now ready for translation using Android string resources.

## 0.11.1

- A simpler text picker with date and signature-name buttons, plus saved entries you can tap to insert.
- More compact saved-text cards with edit and delete beside the title.
- Export uses only its icon in the toolbar.

## 0.11.0

- A clearly labeled Export button opens the save/share options.
- Insert today's date or a name from your signature library as editable text.
- Save and reuse addresses, contact details, and other text across forms. Add, edit, and delete entries, or save text already placed on a PDF.

## 0.10.2

Changes since 0.7.0:

- Rounded corners for squares and rectangles, with an adjustable radius.
- Quick color, stroke-width, and text-size pickers in the editing toolbar.
- Edge and center alignment with visual guides and haptic feedback.
- Precise 1 px or 5 px nudging; hold an arrow to keep moving.
- Change text colors and font sizes without dismissing the keyboard or losing zoom.
- Cleaner toolbars that hide unnecessary controls while typing.
- Smoother dragging and steadier placement when lifting your finger.
